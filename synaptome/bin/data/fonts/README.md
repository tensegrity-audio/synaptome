# Synaptome UI font

The operator interface uses GNU Unifont 17.0.05 (`unifont-17.0.05.otf`).
The font is rasterized at the requested UI size so fractional app text scaling
does not enlarge a pre-rendered bitmap.

- Source: https://ftp.gnu.org/gnu/unifont/unifont-17.0.05/
- Project: https://www.unifoundry.com/unifont/
- License: SIL Open Font License 1.1 (see `OFL-1.1.txt`)
- SHA-256: `85701AB9B1E251EE16F4DF00B13F22EAC311D72B7DAB427A7D975FE7F5064702`

If the file is unavailable or cannot be loaded, the app logs one warning and
continues with the built-in openFrameworks bitmap font.
